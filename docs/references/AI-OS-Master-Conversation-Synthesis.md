# 0. Tujuan Dokumen

Dokumen ini merangkum dan menyatukan seluruh arah pengembangan sistem AI Smarteducafe yang dibahas dalam percakapan menjadi satu kerangka kerja yang dapat digunakan berulang.

Tujuan utamanya adalah agar Smarteducafe tidak memiliki kumpulan prompt yang terpisah-pisah, tetapi memiliki satu **AI Operating System** yang:

- dapat dipakai oleh banyak peran;
- konsisten lintas platform AI;
- terhubung ke kurikulum, operasional, marketing, project management, dan manajemen;
- menghasilkan evidence;
- memiliki quality control;
- dapat diperbarui;
- dapat dikembangkan menjadi skill, knowledge base, dashboard, dan aplikasi internal.

Paradigma akhir:

```text
Bukan:
Topik → Prompt → Output

Tetapi:
Konteks
→ Tujuan
→ Source
→ Workflow
→ AI Engine
→ Human Review
→ Evidence
→ Decision / Action
→ Learning
→ Knowledge Base
→ Kaizen
```

# 4. Prinsip AI Smarteducafe

## 4.1 Human-Led

AI bukan pengambil keputusan akhir.

Manusia tetap menentukan:

- tujuan;
- konteks;
- prioritas;
- keputusan;
- validasi;
- eskalasi;
- safeguarding.

## 4.2 AI-Augmented

AI membantu:

- mempercepat;
- merangkum;
- menganalisis;
- membuat variasi;
- mendeteksi pola;
- menghasilkan draft;
- membantu problem solving.

## 4.3 Source-Grounded

Untuk pekerjaan yang membutuhkan fakta, materi, SOP, kebijakan, asesmen, atau laporan:

- gunakan source;
- pastikan source dapat ditelusuri;
- pisahkan fakta dan asumsi;
- jangan membuat data;
- lakukan human verification.

## 4.4 Evidence Over Opinion

Output penting harus memiliki evidence.

```text
Task
→ Output
→ Evidence
→ Reviewer
→ Verification
```

## 4.5 Outcome Over Activity

Banyak aktivitas bukan ukuran keberhasilan.

Pertanyaan utama:

> Apakah aktivitas menghasilkan outcome?

## 4.6 System Before Blame

Jika terjadi kegagalan, diagnosis harus memeriksa:

- brief;
- skill;
- workload;
- dependency;
- timeline;
- SOP;
- komunikasi;
- approval;
- system gap.

## 4.7 Frictionless First

Workflow harian harus cepat.

Target:

- simple input;
- maksimal tiga prioritas;
- quick update;
- template;
- voice note bila perlu;
- output terstruktur.

## 4.8 Human-in-the-Loop

AI dapat:

- menganalisis;
- menyarankan;
- membuat draft;
- membuat scoring awal.

AI tidak menjadi keputusan tunggal untuk:

- safeguarding;
- keputusan karier;
- disiplin;
- publikasi SOP;
- keputusan strategis besar;
- data sensitif.

# 30. AI Governance

AI boleh digunakan untuk:

- ide;
- variasi;
- feedback;
- summary;
- analysis awal;
- drafting.

AI tidak boleh digunakan untuk:

- membuat data palsu;
- output tanpa verification;
- fake testimonial;
- claim hasil;
- menggantikan safeguarding;
- keputusan high-impact tanpa manusia.

# 31. Data Governance

Prinsip:

- single source of truth;
- role-based access;
- consent;
- anonymization;
- no sensitive data in open group;
- access removed when staff leaves;
- audit log;
- version control.
